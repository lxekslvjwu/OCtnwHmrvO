# 项目简介

## 核心功能
- 基于YOLOv8的玉米杂草检测系统，支持识别'Maize'和'Weeds'两类目标
- 提供完整源码、5660张标注数据集、训练好的模型及训练结果
- 支持多种输入方式：单张图片、图片文件夹、视频文件和本地摄像头
- 界面功能包括：实时显示目标位置、目标总数、置信度等信息
- 支持自定义置信度和IOU阈值
- 支持选择显示标签和原图
- 支持选择检测模型
- 支持批量检测并查看所有检测结果
- 支持检测结果保存

## 适用场景
- 农业领域玉米种植中的杂草自动识别
- 农作物生长监测与病虫害防治
- 农业科研与教学演示
- 智能农业系统中的视觉检测模块

## 技术特点
- 基于Python3.9开发，使用opencv-python、PyQt5、ultralytics、torch1.9等技术栈
- 提供Pycharm+Anaconda或VSCode+Anaconda两种开发环境选择
- 包含完整UI界面源文件、图标和项目运行教程
- 预配置环境可直接使用，无需额外设置
